작성 기준: 2026-09-29 / 담당자: __________ / 확인일: __________

담당자께서 빈칸을 채워 주세요. 모르면 **미확인**, 측정하지 않았으면 **미측정**으로 남겨 주세요. 이 문서는 배선·통전 절차나 구동 승인이 아닙니다.

현재 공유받은 정보는 Mega 2560, MDD10A, VOLTON 24V 10Ah, MC-40a/DC 24V 코일입니다. **29.4V는 사용자 예상값이며 실측값이 아닙니다.** Arduino가 비상정지 때 계속 켜진다는 말씀도 실제 시험 결과와 구분합니다.

## 핀 기준과 혼동 주의

M1→M4 순서로 PWM **11/44/12/45**, DIR **34/36/35/37**, Encoder A **3/18/19/20**, B **30/31/32/33**을 설계 기준으로 사용합니다. 바퀴 위치·encoder 전진 부호는 아직 확정하지 않았습니다.

**A8은 전원 상태 입력 후보이고 실제 연결·극성은 미확인입니다. A3는 배터리 전압 측정 후보로 별개입니다.** A3를 쓰신다면 분압 저항·기준 전압·입력 보호 정보도 적어 주세요: __________. 접촉기 단자 번호는 Arduino pin 번호가 아닙니다. 배터리 전압을 GPIO에 직접 연결하지 않는 보호 회로인지 담당자께서 확인해 주세요.

## 작성 후 처리

전원 구성이 정해지지 않거나 핵심 항목이 미확인이면 **실제 출력 잠금을 유지합니다.** 답변을 받은 뒤 전원 감시·실제 출력 코드의 남은 부분을 구성하고, 업로드·최초 구동은 담당자와 별도 확인합니다. 서류 작성만으로 모터가 바로 돌도록 바꾸지 않습니다.
