# 실차 매핑·왕복 주행 준비 체크리스트

작성일: 2026-09-28. 빈칸은 미측정입니다. CAD 값과 과거 기록을 실측 완료로 취급하지 않습니다.
체크는 담당자가 근거와 오차를 확인한 뒤 표시합니다. 이 문서는 구동 승인 또는 설정 자동 적용 기능이 아닙니다.

## 1. 먼저 알고 계실 결론

- ROS2 Jazzy·SLAM·Nav2는 합성 LiDAR/odom 기반으로 구현되어 있습니다. 가상 지도와 가상 목표 이동 시험이 가능합니다.
- RViz2는 시각화 도구입니다. RViz가 켜진다고 실차 위치 추정이나 모터 연동까지 완료된 것은 아닙니다.
- 실제 매핑은 정확한 `/scan`, `/odom`, `map → odom → base_link → laser` TF와 시간이 필요합니다.
- 현장 사진은 배치 참고용입니다. 사진으로 통로 폭·안전 여유·회전 가능 여부를 확정하지 않습니다.
- 이번 작업에서는 실제 모터 구동·firmware 업로드를 하지 않습니다. 아래 동적 시험은 별도 준비 확인 후 진행할 항목입니다.

CAD에서 더 확인할 수 있는 항목: 최종 조립 기준 바퀴 중심, 센서 기준점, 외곽/회전 포락, 간섭입니다.
다만 최종 케이스·센서 부품과 전방 축이 조립에 반영되어 있어야 합니다. 바퀴 미끄럼·제동거리·encoder 오차는 CAD로 확정할 수 없습니다.

## 4. 모터 비활성 센서·encoder 점검

계산: count/rev = |Δcount| / 실제 바퀴 회전수. 현재 펌웨어의 디코딩 단위를 유지합니다.

- [ ] LiDAR `/scan`의 frame_id ___ / 주기 ___ Hz / range_min ___ m / 유효 range_max ___ m를 확인했습니다.
- [ ] 알려진 거리의 표적(실측 ___ m)을 앞·좌·우에 놓고 각도 부호와 측정거리 ___ m를 확인했습니다.

## 5. 준비 확인 후에만 하는 저속 동적 시험

아직 실시하지 않았습니다. 모터 구동 승인, 주변 통제, 물리 비상정지, 상한 PWM 확인을 먼저 받아야 합니다.

- [ ] Twist(m/s·rad/s) → firmware percent 변환을 보정하고 포화·deadman·단일 serial gateway를 검증했습니다.
- [ ] 직진 실거리 ___ m / odom ___ m, 횡이동 실거리 ___ m / odom ___ m를 반복 측정했습니다.
- [ ] 회전 실각도 ___ ° / odom ___ °, 180° 회전 오차 ___ °를 encoder + 카메라로 확인했습니다. IMU는 전제하지 않습니다.
- [ ] 무부하·5개 예상 적재 상태별 출발/주행/감속 PWM, 속도, 제동거리, 바퀴 슬립을 측정했습니다.
- [ ] 사람 감지 지연 ___ s + 제어 지연 ___ s + 감속거리 ___ m + 범퍼 오프셋 ___ m + 여유 ___ m를 고려했습니다.
- [ ] 카메라 기준 0.50 m 정지 요청값이 실제 정지에 충분한지 확인했습니다. 충분하지 않으면 속도/감지 임계값을 조정해야 하며, 0.50 m 자체를 안전거리로 보증하지 않습니다.
- [ ] 비상정지·통신 끊김·센서 끊김에서 안전하게 정지하며 재시작 시 임의 출발하지 않습니다.

## 6. 현장 도로·출발/도착점

- [ ] 두 테이프의 안쪽 간격 ___ mm / 테이프 자체 폭 ___ mm / 최협 통로 폭 ___ mm.
- [ ] 왕복 경로 길이 ___ m / 최소 곡률반경 ___ mm / 출발·도착 회전 가능 공간 ___ × ___ mm.
- [ ] 테이블 돌출·사람 통행·낙하 위험·바닥 반사·조명 차이를 확인했습니다.
- [ ] 출발 색상 ___ / 도착 색상 ___ / 표식 크기 ___ mm / 정차 오차 허용치 ___ mm, ___ °.
- [ ] 새 현장 map_id ___ / map 파일 ___ / 초기 pose ___ / 출발 pose ___ / 도착 pose ___. 모두 실제 map 좌표 기준입니다.
- [ ] 선 추종과 Nav2 중 현재 제어권을 갖는 노드를 정하고 이중 속도 출력을 막았습니다.

초기 목표는 출발지 ↔ 목적지 한 곳, 도착 후 180° 회전 복귀입니다. 가상 Nav2의 home/destination 버튼은 해당 전체 임무를 구현한 것이 아닙니다.

## 7. 작성 이후

검증 담당자가 위 자료를 검토한 후 m/rad/count 단위로 `src/wafer_cart_mapping/config/measurements.json`을 갱신합니다.
저장소 루트에서 `ros2 run wafer_cart_mapping check_measurements src/wafer_cart_mapping/config/measurements.json`으로 누락을 확인합니다. guard 통과는 수치·필수 확인 여부 검사이며 실차 안전 인증이 아닙니다.
실제 센서 매핑 모드는 모터 출력 없이 별도 확인하고, 그 다음에만 승인된 저속 주행 시험으로 진행합니다.
