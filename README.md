# 웨이퍼로봇

웨이퍼 이송 대차의 **현재 수동 모터 검사 코드와 진단 자료**를 다른 Windows 데스크탑으로 전달하기 위한 저장소입니다.

> 이 저장소를 다운로드하거나 설치하는 것만으로 Arduino 업로드·모터 구동이 시작되지는 않습니다. 실제 수동 조작 메뉴는 출력이 가능하므로 전원·배선·시험 준비를 확인한 뒤 사용하세요.

## 먼저 시작하기

1. 이 저장소의 ZIP을 다운로드해 완전히 압축 해제하거나 clone합니다.
2. [README_FIRST.md](README_FIRST.md)를 읽습니다.
3. Windows Python 3.13 64bit(Launcher·Tcl/Tk 포함)를 설치합니다.
4. `START.cmd` → **1번** 환경 설치 → **3번** 장치 없는 시험 순서로 진행합니다.
5. 배터리 분리·Arduino USB만 연결 후 **2번**으로 COM 번호를 확인하고 **4번**으로 정지 진단을 실행합니다.

실제 수동 터미널은 **5번**, GUI는 **6번**입니다. 별도 확인 입력이 있으며 시작 출력은1%입니다. 자동 주행이나 전원 ON 시험의 안전 승인을 뜻하지 않습니다.

## 포함한 파일

- 수동 터미널·Tk GUI·serial gateway·진단·101개 단위시험.
- Arduino Mega 펌웨어 소스와 PlatformIO 설정, 2026-10-09 업로드본 HEX.
- 별도 출력 잠금 엔코더 핀 탐색 소스, C++ 모의시험 소스.
- 가상 부스/운동 모델과 CAD·실측 참고 설정.
- 핀 보고서·사용 전 점검표 PDF, 배선 사진6장.
- 2026-10-09 진단 성공 및 과거 실패 로그, 파일 SHA256 목록.

Python·pyserial로 현재 실제 수동 조작 경로를 실행할 수 있습니다. C++ 기반 가상 지도 GUI에는 WSL Ubuntu-24.04와 g++가 필요하고, 펌웨어 재빌드에는 PlatformIO가 필요합니다. ROS2·Nav2·카메라 전체 환경은 이 수동검사 전달본의 범위가 아닙니다.

## 확인된 범위와 남은 사항

- 원래 PC의 2026-10-09 시험: 모터 전원 OFF에서 명령8회 수락, PWM/DIR 내부 레지스터와 정지 응답 확인.
- 2026-10-10 전달본: ZIP 재압축 해제 후 파일 무결성·Python 모의시험·단위시험101개·Python44개 파일 구문 검사 통과.
- 새 데스크탑의 실제 COM·GUI·하드웨어 동작은 그 PC에서 별도 확인해야 합니다.
- 실제 모터 회전, 전원·드라이버 출력·배선 도통 정상은 아직 확정하지 않았습니다.
- 4륜 실차 매핑 미검증으로 주행 잠금 유지. 화면의 모터 위치는 추정이며 사진 스티커와 다를 수 있습니다.
- 카메라 사람 정지·물리 비상정지 피드백은 현재 수동 경로에 연결되지 않았습니다.

최신 시험 이력은 [수동 출력 연결 문서](docs/25_MANUAL_OUTPUT_CONNECTION.md), 출처는 [가져온 파일 기록](imports/README.md)을 참고하세요. `FILE_MANIFEST.json`은 최초 전달본105개 파일의 해시 목록이며 이 GitHub용 README 등 이후 추가 파일은 포함하지 않습니다.

이 저장소는 배선 사진·장치 식별값·과거 로컬 경로를 포함하여 비공개로 생성합니다. 팀 외부에 공개하기 전에 자료 공유 범위를 검토하세요.
