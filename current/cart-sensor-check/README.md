# 카메라 + LiDAR 무구동 점검

## 실행

```powershell
& 'C:\Users\H\Desktop\로봇 자율주행\cart-sensor-check\start.cmd'
```

기존 카메라/LiDAR 창은 먼저 종료합니다. 새 창에서 두 센서를 함께 시작합니다.
StreamCam의 현재 DirectShow 번호는 0입니다. USB 순서가 바뀌면 재확인이 필요합니다.
LiDAR는 실제 확인한 CP210x VID 10C4 / PID EA60 / serial 0001만 허용합니다.
COM7과 Arduino는 거부하며, 대차 모터 명령 코드가 없습니다.

## 화면 사용법

1. 왼쪽 YOLO 박스를 클릭하면 카메라 표적 종류를 선택합니다. 기본은 red_box입니다.
2. 오른쪽 레이더 측정점을 클릭하면 해당 방위와 거리를 중심으로 측정 구간을 선택합니다.
3. 방위, 각도폭, 중심거리, 거리폭을 직접 입력하고 `구간 적용`할 수도 있습니다.
4. 초기 구간은 raw 0° ±5°, 중심 55cm ±25cm입니다. 현장 52cm 후보와 배경을 분리하기 위한 임시값이며, 센서-카메라 보정값이 아닙니다.
5. `기준 거리 잡기`를 누르고 상자를 앞뒤로 옮기면 기준 대비 변화와 최근 3초 변화폭을 확인할 수 있습니다.
6. 상자를 치웠다가 놓아 카메라 인식과 선택 구간 변화가 같이 일어나는지 비교합니다. 구간 밖으로 움직이면 거리 무효가 정상입니다. 자동 재추적은 하지 않습니다.
7. `수치 CSV 저장`은 이 폴더의 logs에 최근 최대 6000개 수치를 UTF-8 BOM CSV로 저장합니다. 영상은 저장/전송하지 않습니다. 종료 시 자동 저장하지 않습니다.
8. `둘 다 종료` 또는 창 닫기로 센서 스캔/카메라 수신을 종료합니다.

## 중요한 한계

- 카메라 선택과 LiDAR 선택은 독립적입니다. 자동으로 같은 물체라고 판단하지 않습니다.
- 구간 내 표면이 바뀌거나 다른 물체가 들어와도 거리값이 나올 수 있습니다.
- 표시값은 LiDAR 센서 원점에서 측정점까지의 거리입니다. 차체-테이블 여유 간격이나 FOUP 정렬 오차가 아닙니다.
- 각도는 기존 1차 raw 방위입니다. 삼각측량 각도 보정, 카메라 내부/외부 보정, 장착 기울기·높이·평행 이동 보정은 적용하지 않았습니다.
- 카메라 bbox 중심 X/Y는 픽셀 오차입니다. 잘린/중복된 물체에는 경고하며 이동 명령을 생성하지 않습니다.
- 체크섬 검증 후 각도별 최신 데이터만 사용하며 0.35초 지난 점과 0거리 점은 거리 계산에서 제외합니다. 3점 미만 또는 구간 거리폭 20cm 초과면 무효입니다.
- 그래프 변화폭은 움직임과 잡음을 모두 포함합니다. 물체를 고정한 경우에만 반복성 참고값이 됩니다. 실측 정확도는 줄자 등 독립 기준과 비교해야 합니다.
- 잘 돌아가는 기존 모터·주행 UI와 기존 카메라 프로그램은 수정하지 않았습니다.
