# 표적 중앙 맞춤 · 화면 전용

## 실행과 범위

`start-preview.cmd`를 실행합니다. 별도 창이며 기존 대차 UI/모터 코드와 연결하지 않습니다.

```powershell
& 'C:\Users\H\AppData\Local\Programs\Python\Python313\python.exe' -B 'C:\Users\H\Desktop\로봇 자율주행\cart-target-preview\preview.py'
```

1. 다른 카메라 앱을 닫고 카메라 번호(기본 0) → `카메라 시작`을 누릅니다. **기본 모드는 YOLO이며 기존 6종 학습 모델이 미리 선택되어 있습니다.** 실패하면 종료 후 번호 또는 DSHOW/MSMF를 바꿉니다.
2. `색상 클릭`: 배경과 구별되는 선명한 단색 물체를 클릭합니다. 검정/흰색/회색은 지원하지 않습니다. 빨강·파랑 등 같은 색 후보가 여러 개면 판단을 중지합니다.
3. `YOLO`: 기본 모델은 `six_class_detection_training/runs/segment/train/weights/best.pt`입니다. 카메라 시작 후 검출 박스를 클릭합니다. 각 박스에 종류·신뢰도·목표 X 대비 픽셀 오차가 표시되고, 클릭한 종류의 표적이 하나이면 하단에 중앙 오차가 표시됩니다. 모델에 학습된 종류만 인식합니다. 자동 다운로드·새 학습·색상 대체 실행을 하지 않습니다. ultralytics가 없으면 오류를 표시합니다.
4. 노란 세로선이 목표 X, 점선 범위는 픽셀 허용 오차, 초록 박스/점은 선택 표적입니다. 화면 기준 왼쪽/오른쪽과 수평·세로 픽셀 오차를 표시합니다. 세로 오차는 참고값입니다.
5. 수평 허용 범위에서 새 프레임이 0.5초 이상 연속 유지되면 `수평 중앙 일치`로 표시합니다. 주차 완료/거리 확보/방향 정렬이 아닙니다.
6. `현재 표적 X를 목표로`는 목표 수평 위치만 변경합니다. `화면 중앙으로 복원`으로 되돌립니다. 설정은 종료하면 초기화합니다.
7. 우클릭 또는 `표적 해제`로 해제합니다. `카메라 종료` 후 다시 시작할 수 있습니다. `모의 영상`은 실제 카메라 없이 합성 빨간 표적을 사용합니다.

## 기존 기능과 관계

`ROBOT-motor-review-928b2a8/visualization/track_and_approach_single.py`에 색상/YOLO 추적과 회전 정렬 후 접근 기능이 이미 존재합니다. 그 실행 파일은 라이다·모터 연결을 포함하므로 이번 도구에서 실행하거나 import하지 않습니다.

기존 `common/color.py`의 순수 색상 분류/마스크 함수만 읽어 사용합니다. 해당 파일과 기존 펌웨어, 수동 모터 시험, 메인 UI, driver_adapter는 변경하지 않습니다. 원본 폴더를 이동하면 색상 함수 로드가 실패할 수 있습니다.

## 제한과 중단 표시

- COM/Arduino/라이다 연결 및 모터 명령 경로가 없습니다. 모터를 움직이기 위한 옵션도 없습니다.
- 픽셀 오차는 mm·거리·대차 이동량이 아닙니다. 좌측 정측면·직립 장착을 확인한 경우에만 전진/후진 방향 안내를 표시합니다. 실제 모터 명령은 없습니다.
- 색상이나 클래스만으로 물체의 고유 신원을 보장하지 않습니다. 같은 후보가 둘 이상이면 중지하지만, 다른 동일 색/종류 물체 하나만 나타나면 구분하지 못할 수 있습니다.
- 0.5초 이상 오래된 영상은 무효입니다. 동일 영상 바이트가 2초 이상 반복되면 영상 정지 의심으로 표시합니다. 정적인 정상 장면도 의심 표시가 가능하며 모든 카메라 고장을 검출하는 장치는 아닙니다.
- YOLO 추론이 느려 프레임이 0.5초 이상 오래되면 유효 판정을 하지 않습니다. 화면과 판정은 같은 캡처 프레임을 사용합니다.
- 캡처가 드라이버 내부에서 멈추면 종료 요청 후 작업이 풀리기 전까지 재시작을 막습니다. 프로그램을 종료하고 USB/카메라 점유 상태를 점검합니다.
- 이미지 저장, 녹화, 외부 영상 전송은 하지 않습니다.
- 실제 카메라 종류·USB 수신·현장 표적 반복성은 합성 영상 테스트와 별도로 확인해야 합니다.

## 2026-10-14 좌측 카메라 이동 안내

- 카메라는 대차 왼쪽에 직립으로 고정하고 왼쪽 정측면 바깥을 바라보는 조건입니다. 기울이거나 전후를 바라보는 장착은 이 안내의 검증 범위가 아닙니다.
- 카메라 시작 후 YOLO 박스를 클릭하고, `카메라 직립 · 대차 좌측 바깥을 봄 확인`을 체크합니다. 확인 전에는 위치만 표시하고 이동 안내는 보류합니다.
- 반전되지 않은 영상에서 표적이 화면 오른쪽이면 대차 전진, 왼쪽이면 후진으로 수평 중앙을 맞춥니다. 영상의 왼쪽을 대차 왼쪽 평행이동으로 해석하면 안 됩니다.
- 입력 영상 자체가 좌우 반전되어 있다면 `입력 영상이 좌우 반전됨`을 체크합니다. 이 옵션은 방향 해석만 바꾸며 영상을 다시 뒤집지는 않습니다. 고정된 카메라 앞에서 표적을 대차 전방 쪽으로 옮겨 화면 오른쪽(반전 시 왼쪽)에 나타나는지 모터 없이 먼저 확인합니다.
- 하단에 화면 중앙 대비 왼쪽/오른쪽, 위/아래, X/Y 픽셀 오차와 대차 전진/후진 안내를 표시합니다. 안내는 사용자 지정 노란 목표선과 무관하게 항상 실제 화면 중앙을 기준으로 합니다. 목표선을 변경하면 흰 점선이 화면 중앙을 표시합니다.
- 세로 오차로 좌우 평행이동이나 회전 방향을 추정하지 않습니다. 거리·각도·이동량·충돌 여유는 미측정입니다. 수평 허용 범위는 주차 완료를 뜻하지 않습니다.
- 표적 미선택/상실/중복/화면 밖 잘림, 오래된 영상, 영상 정지 의심, 카메라 종료/수신 오류에서는 이동 안내를 중지합니다.
- 합성 입력 및 실제 Tk 위젯 검사 20개 통과: 정상/반전 전후 매핑, 장착 확인, 세로 위치, 중앙 범위, 무효 데이터, 목표선 독립성, 체크버튼·종료 동작, 1120×820 및 960×720 배치, 기존 원본 4개 파일 SHA256 보존을 확인했습니다. 실제 좌측 장착·현장 표적 인식 및 이동 방향 실물 검증은 별도입니다.

## 2026-10-14 화질·큰 화면 개선

- 기본 캡처 요청을 기존 640×480/15fps에서 Full HD 1920×1080/30fps로 변경했습니다. MJPG를 먼저 요청하며 실제 지원 여부는 카메라/드라이버/USB 환경에 따라 다릅니다.
- `영상 품질`에서 Full HD, HD 1280×720/30fps, 기존 640×480/15fps 중 선택합니다. 시작 후에는 변경을 잠그며 `카메라 종료` 후 다시 선택합니다. 느리거나 열기에 실패하면 HD로 낮춰 재시도하세요. 자동으로 다른 카메라를 열거나 해상도를 몰래 낮추지 않습니다.
- 요청 해상도와 실제 수신 프레임 해상도를 구분하여 표시합니다. 다르면 `요청과 다름`이 표시됩니다. fps는 요청값이며 실제 추론·표시 속도 보장이 아닙니다.
- 원본 영상 전체를 종횡비 그대로 표시하고 LANCZOS로 화면 크기에 맞춥니다. 앱 자체의 디지털 줌/자르기는 없습니다. `영상 크게 · F11`은 전체 화면에서 일부 설정 줄을 숨겨 영상 영역을 늘립니다. `Esc` 또는 버튼으로 원래 화면으로 복원하며 상태·위치·이동 안내는 계속 표시합니다.
- 고해상도/16:9는 광학 촬영 시야 확대를 보장하지 않습니다. 센서 모드에 따라 보이는 범위가 달라질 수 있고, 렌즈 밖의 장면을 소프트웨어로 만들지는 않습니다. 더 넓은 실제 범위가 필요하면 카메라 위치·대상과의 거리 또는 렌즈를 검토해야 합니다.
- YOLO 추론 크기 `imgsz=640`은 속도를 위해 유지했습니다. 표시 영상은 고해상도 원본이며 검출 박스는 원본 좌표를 사용합니다. 픽셀 허용 오차는 원본 해상도 기준이므로 해상도를 바꾸면 같은 숫자의 의미가 달라집니다. 광학 보정·인식률 향상 또는 실물 방향 검증이 완료됐다는 뜻은 아닙니다.
- 연결 장치 목록에서 Logitech StreamCam을 확인하고 DirectShow 형식 목록에서 1920×1080 MJPG 지원을 확인했습니다. 실제 15프레임 수신 시도는 `Could not run graph`로 실패했습니다(다른 앱 점유 가능성). 따라서 실제 Full HD 수신·시야 변화는 아직 미검증입니다.
- 자동 검사 23개 통과: 기존 20개 항목에 품질 요청 순서/실제 해상도 표시, 품질 선택·잠금·큰 화면 복원, Full HD 프레임 전체 표시·물체 클릭 좌표를 추가했습니다. 작은 창 배치 결함 수정 후 재검증했습니다. 원본 모터 관련 4개 파일의 SHA256도 보존됐습니다.
- 공식 StreamCam 사양 참고: https://www.logitech.com/en-us/shop/p/streamcam (Full HD, 최대 60fps, 시야각 78°). 앱 기본 요청은 30fps이며 하드웨어 실제 성능 시험과 구분합니다.
- 실제 Tk 창에서 모의 영상 기본 화면과 F11 전체 화면을 열어 품질 선택, 원본 비율 유지, 상태·이동 안내 표시 및 영상 영역 확대를 시각적으로 확인했습니다. 이 확인은 실제 카메라 화질 검증과 다릅니다.
